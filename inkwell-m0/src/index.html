These numbers are a floor, not the truth. JS cannot see the compositor, display scanout, or LCD response — add roughly 8–20 ms on a 60 Hz panel.

Ground truth: film the screen and your pen tip together at 240 fps (4.17 ms per frame) and count frames between the tip moving and the ink moving. Write the number in your README. Nothing in software replaces this.

Exported capture JSON uses the same stroke schema as the single-PDF proof, so a real Huion capture converts to a real PDF with no glue code.
