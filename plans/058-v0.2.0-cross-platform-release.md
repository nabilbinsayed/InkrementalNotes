# Plan 058 — v0.2.0 Cross-Platform Release & Durability Hardening

## Overview
Prepares, validates, and packages **Inkwell v0.2.0** for seamless cross-platform deployment across Windows (NSIS installer & portable ZIP) and Linux (universal AppImage, Debian package, Fedora RPM, and portable tarball).

## Objectives
1. **Windows Portability & MSVC C Runtime Isolation**:
   - Configure `-C target-feature=+crt-static` across `.cargo/config.toml` to eliminate runtime dependencies on `VCRUNTIME140.dll` / `VCRUNTIME140_1.dll`.
   - Bundle `pdfium.dll` in both root and `bin/` directories in portable distribution zips.
   - Harden `Launch Inkwell.bat` to set `PATH` and `PDFIUM_DLL_DIR` and surface helpful guidance if WebView2 Runtime is missing.
2. **Deep Recursive PDFium Library Discovery**:
   - Update `init_pdfium` and `init_pdfium_from_dir` in `inkwell-pdf` to recursively scan application, resource, and ancestor directories up to depth 4.
   - Filter out 0-byte placeholder files (`meta.len() > 1024`) to prevent dummy file binding failures.
   - Add IPC command `check_pdfium_status` and frontend bridge `ipc.checkPdfiumStatus()` for proactive health checks.
3. **Linux Distribution Packaging Integrity**:
   - Ensure `Launch Inkwell.sh` exports `PDFIUM_DLL_DIR` and includes root `$DIR` in `LD_LIBRARY_PATH`.
   - Bundle dual executable aliases (`inkwell-app` and `Inkwell`) and dual `libpdfium.so` paths in Linux portable tarball.
   - Add `rpm-build` dependency to Fedora build container.
4. **Feature Completion & Verification**:
   - Image Copy/Paste & Drag-Drop: Ingest screenshots from system clipboard, drag-and-drop image files, 8-handle transformation, and native PDF embedding on save.
   - Inking Overhaul: Live cubic Bézier smoothing, velocity forward prediction, and adaptive stabilization.
   - Dedicated Shortcuts: `R` (Rectangle), `O` (Ellipse), `L` (Line), `K` (Laser Pointer), `S` (Text Selection).
   - Automated CI Test Suite: Wire `test_image_copypaste.py` into GitHub Actions workflow.
